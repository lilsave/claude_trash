# Урок 6. Записываем мелодию в SLOOP

Бит у тебя уже записан, теперь очередь мелодии. Сегодня ты запишешь «Оду к радости» на трек 3 двумя способами: живьём и по шагам. Помнишь из урока 4, что клавиши в SLOOP могут быть шагами? С мелодией работает то же самое — только в шаг пишется нота.

## Способ 1. Живьём, со щелчками метронома

```panel
hl=SELECT:1 REC:2 KNOB2:3 KNOB3:4 PLAY:5
caption=Темп, запись, длина, старт со щелчков, поехали
```

1. Трек **3** (ALGORITHM). Сначала очисти его: **держи REC** около 2 секунд, пока не заполнится кольцо на экране.
2. На экране TRACKS крути **SELECT** — поставь темп **90**.
3. Нажми **REC** — экран *REC READY*.
4. **KNOB 2** (length) — **4** такта.
5. **KNOB 3** (start) — **count**: сначала щелчки, потом запись.
6. Нажми **PLAY**: SLOOP отсчитает «4-3-2-1», и на «раз» играй первые 4 такта «Оды».
7. Луп сразу начнёт повторяться. **REC** — остановить запись.

Промахнулся? **EDIT + OCT−** — отмена. SLOOP сам выравнивает ноты по сетке, так что маленькие неточности исчезнут.

## Способ 2. По шагам — без спешки, нота за нотой

Этот способ хорош в самолёте: можно не попадать в ритм. Хитрость: сделаем **один шаг = одна четверть** (DIV 1/4). Тогда «Оду» можно просто нажимать по нотам.

```panel
hl=SEQ:держи KNOB2:DIV KNOB4:LEN
caption=Держи SEQ: KNOB 2 = DIV 1/4, KNOB 4 = LEN 16
```

1. Трек 3, очисти его (держи REC).
2. **Держи SEQ**, крути **KNOB 2** до **1/4** и **KNOB 4** до **16**. 16 шагов по четверти = 4 такта.
3. Отпусти SEQ и **коротко нажми SEQ** — откроется страница **STEP** (если открылась другая, нажми SEQ ещё раз).
4. **KNOB 1** — курсор на шаг 1.
5. Нажимай ноты по очереди: каждая нажатая клавиша записывается в шаг, курсор сам идёт дальше.
6. Где нота длинная (половинная), на следующем шаге поверни **KNOB 3 (TIME)** на **TIE** — это «держать дальше».

```panel
hl=SEQ:STEP KNOB1:шаг KNOB2:нота KNOB3:TIE KNOB4:флаг
caption=Страница STEP: KNOB 1 — курсор, KNOB 3 — NOTE / TIE / REST
```

Вот упрощённая «Ода» для такого ввода (вместо «ми-с-точкой» — ровные четверти):

```song
title=«Ода к радости» для ввода по шагам
bpm=90
notes=E4 E4 F4 G4 | G4 F4 E4 D4 | C4 C4 D4 E4 | E4 D4 D4-
div=1/4
note=Открой «Как ввести по шагам»: каждая клеточка — один шаг. Пустая голубая клетка — TIE.
```

7. Нажми **PLAY** — мелодия играет сама, вместе с битом из уроков 4–5. Это уже музыка из двух инструментов.

> **Что ты узнал:** REC — запись живьём, STEP — запись по шагам. DIV — сколько длится один шаг (1/4 — четверть, 1/16 — шестнадцатая). LEN — сколько шагов в лупе. TIE — продлить ноту.
