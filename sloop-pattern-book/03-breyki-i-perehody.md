# Глава 3. Брейки, сбивки и переходы

[← Глава 2](02-udarnye.md) · [Оглавление](README.md) · [Глава 4. Аккорды →](04-akkordy.md)

Бит, который 3 минуты играет без изменений, надоедает за 30 секунд. Здесь — готовые сбивки и три способа их встроить в SLOOP 2.4.

## 3.1. Три способа сделать брейк

| Способ | Как | Когда |
| --- | --- | --- |
| **Последний такт в паттерне** | LEN 32 или 64: последние шаги — сбивка. Удвоение: **EDIT + KNOB 2** вправо (паттерн копируется после себя), потом правишь копию | сбивка каждые 2 или 4 такта, автоматически |
| **Шаги FILL ONLY** | на шагах сбивки ставь условие **FILL ONLY** (SEQ + шаг + OCT+), на мешающих — **NO FILL**. Вызов: **GLO + клавиша 10** (весь следующий такт) или **GLO + клавиша 9** (пока держишь) | сбивка «по кнопке», живьём |
| **Отдельная секция** | сохрани такт-сбивку в секцию (SAVE + клавиша 5–8) и вставь в цепочку / песню | переходы между частями песни |

> Любую сбивку ниже можно вставить в шаги 13–16 (последнюю группу) любого бита из главы 2 — просто замени эту группу.

## 3.2. Короткие сбивки (последняя доля, шаги 13–16)

Показана только последняя группа такта; шаги 1–12 — твой бит.

### F01 · Дробь малого

```
            ...|4e+a
 3 SNARE    ...|XXXX
```

Сделай уровни **SOFT, SOFT, NORM, HARD** (шаги 13–16) — нарастание.

### F02 · Дробь рэтчетами

```
            ...|4e+a
 3 SNARE    ...|X234
```

Удары всё чаще: x1, x2, x3, x4. Один такой шаг (`4`) — классическая трэп/EDM-подводка.

### F03 · Томы вниз

```
            ...|4e+a
11 HTOM     ...|XX..
10 LTOM     ...|..XX
```

### F04 · Флэм-подхват

```
            ...|4e+a
 3 SNARE    ...|..gX
 1 KICK     ...|X...
```

Призрак + удар — «т-ТА» перед «раз».

### F05 · Томы по кругу (синтвейв, рок)

```
            ...|4e+a
11 HTOM     ...|X.X.
10 LTOM     ...|.X.X
 3 SNARE    ...|....
```

С ревербом ударных 40 % — тот самый звук 80-х.

### F06 · Открытый хэт-выдох

```
            ...|4e+a
 6 OHAT     ...|..X.
 5 HAT      ...|X...
 3 SNARE    ...|X...
```

Самая скромная сбивка — для хауса и диско. Убери бочку с шага 13, будет «провал».

### F07 · Тишина перед «раз»

```
            ...|4e+a
все         ...|....
```

Сотри всё на шагах 13–16 (**EDIT + клавиша** держи, пока плейхед проходит эти шаги — так стирается только кусок). Пауза перед припевом бьёт сильнее любой дроби.

## 3.3. Полные такты-брейки (16 шагов)

### F08 · Классический рок/поп-брейк

```
            1e+a|2e+a|3e+a|4e+a
11 HTOM     ....|....|XX..|....
10 LTOM     ....|....|..XX|....
 5 HAT      X.X.|X.X.|....|....
 3 SNARE    ....|X...|....|xXXO
 1 KICK     X...|....|....|....
```

### F09 · Хип-хоп «стоп»

```
            1e+a|2e+a|3e+a|4e+a
12 CRASH    X...|....|....|....
 3 SNARE    ....|....|....|...g
 1 KICK     X...|....|....|....
```

Удар + крэш и тишина такт — вокалист «кричит в пустоту». Работает в любом жанре.

### F10 · EDM-подъём (4 такта, LEN 64)

**Кит 909 или HOUSE**

```
такт 1      1e+a|2e+a|3e+a|4e+a
 3 SNARE    x...|x...|x...|x...

такт 2      1e+a|2e+a|3e+a|4e+a
 3 SNARE    x.x.|x.x.|X.X.|X.X.

такт 3      1e+a|2e+a|3e+a|4e+a
 3 SNARE    XXXX|XXXX|XXXX|XXXX

такт 4      1e+a|2e+a|3e+a|4e+a
 3 SNARE    2222|2222|OOOO|....
```

Четверти → восьмые → шестнадцатые → 1/32 (рэтчет `2`) и обрыв. Добавь сверху:
- **FX + KNOB 1** вправо медленно, все 4 такта (high-pass на весь микс);
- **FX + клавиша 10** (high-pass sweep) на последнем такте;
- бочку 4/4 оставь в тактах 1–3 и убери в такте 4.

### F11 · Трэп-«выключатель»

```
            1e+a|2e+a|3e+a|4e+a
 5 HAT      4444|....|....|....
 4 CLAP     ....|....|O...|....
 1 KICK     ....|....|....|....
```

Ролл хэтов 1/64 первую долю, потом без бочки и 808 до конца такта. Добавь **FX + клавиша 7** (tape stop) на последней доле — эффектный обрыв перед дропом.

### F12 · Джангл-разрыв

```
            1e+a|2e+a|3e+a|4e+a
 3 SNARE    X.XX|.XX.|XX2X|3434
 1 KICK     X...|..X.|....|....
```

## 3.4. Шаблон «брейк по кнопке» (FILL ONLY / NO FILL)

Это хаус-бит D13 со встроенным брейком. В обычных тактах ты его не слышишь; нажал **GLO + клавиша 10** — следующий такт играет со сбивкой.

**BPM 124 · кит HOUSE**

```
            1e+a|2e+a|3e+a|4e+a
12 CRASH    ....|....|....|....
11 HTOM     ....|....|....|.X.X
10 LTOM     ....|....|....|....
 6 OHAT     ..X.|..X.|..X.|..X.
 4 CLAP     ....|X...|....|X...
 1 KICK     O...|O...|O...|O...
Усл.        ....|....|....|.FNF
```

- Шаги **14 и 16** (томы) — **FILL ONLY**: звучат только в брейке.
- Шаг **15** (открытый хэт) — **NO FILL**: в брейке пропадает.
- Ставится: SEQ + шаг 14 + OCT+ (один раз → FILL ONLY); SEQ + шаг 15 + OCT+ (два раза → NO FILL); шаг 16 — как 14. На плитке появится маленькая **F** или **×**.

Так же сделай брейк в любом бите: **отдели «брейковые» удары на свои шаги** и пометь их F, а то, что должно замолчать, — N. Удобно делать FILL ONLY весь последний шаг-ролл (`4` на малом) и крэш на шаге 16.

> Совет: у синт-треков тоже есть условия шагов. Нота баса или аккорд «FILL ONLY» на шаге 16 + «NO FILL» на шагах 13–15 — и твой брейк по кнопке меняет ещё и бас.

## 3.5. Переходы между частями (секции A–D)

| Переход | Что сделать в SLOOP |
| --- | --- |
| **Куплет → припев** | в последнем такте куплета F10 или F02 + **FX + KNOB 1** high-pass; в припеве добавь CLAP к SNARE, открытые хэты, громче трек 2 (GLO + KNOB 2) |
| **Припев → куплет** | F07 (тишина) или F09 (стоп). Куплет начни без бочки на первом такте |
| **Дроп** | за такт до дропа: **GLO + клавиша** трека баса (1–3, mute), **FX + клавиша 9** (low-pass sweep); на «раз» дропа — всё обратно |
| **Конец песни** | **FX + клавиша 7** (tape stop) на последнем такте или **FX + клавиша 1** (луп 1/4) и отпустить на «раз» |
| **Бридж** | та же секция, но **GLO + клавиши 5–8** (solo): оставь только аккорды и шейкер на 4–8 тактов |

### Быстрая цепочка с брейком

1. Сохрани бит в **A** (SAVE + клавиша 5).
2. Измени последний такт на сбивку, сохрани в **B** (SAVE + клавиша 6).
3. Держи **SAVE** и нажми **1, 1, 1, 2** — цепочка «A A A B» крутится по кругу: три обычных такта (или паттерна) и брейк.

## 3.6. Панч-эффекты как брейки (FX + белая клавиша)

Держишь **FX** и белую клавишу — эффект на весь микс, пока держишь. Не записывается, только живьём.

| Клавиша | Эффект | Как использовать |
| --- | --- | --- |
| 1–4 | луп 1/4, 1/8, 1/16, 1/32 | «заикание» последней доли перед припевом: 1/8 → 1/16 → 1/32 по очереди |
| 5 | статтер триолями | трэп-переход |
| 6 | реверс | перед «раз» новой части |
| 7 | tape stop | конец, обрыв перед дропом |
| 8 | half speed | «замедление» на такт |
| 9 / 10 | low-pass / high-pass sweep | подводки и отводки |
| 11 | phone | куплет «из телефона», потом отпустить |
| 12 / 13 | bit crush / alias | лоу-фай и чиптюн-брейки |
| 14 | gate 1/16 | ритмичная «нарезка» пэдов |
| 15 | эхо (1/8 с точкой) | хвост последнего слова/ноты |
| 16 | tape wobble | лоу-фай «плывущая» кассета |
