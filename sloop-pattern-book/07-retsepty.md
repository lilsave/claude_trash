# Глава 7. Рецепты треков — 20 жанров целиком

[← Глава 6](06-melodii.md) · [Оглавление](README.md) · [Глава 8. Против одинаковости →](08-protiv-odinakovosti.md)

Каждый рецепт собирает **все четыре трека** из кусков книги: ударные (D), бас (B), аккорды (P + ритм R), мелодию (M). Плюс эффекты и структура песни по секциям A–D.

**Как собирать:**
1. SAVE → TOOLS → **NEW** (GO) — чистый проект.
2. Темп, тональность (SEL + клавиша), лад (SEL + KNOB 2), KEYS = WHITE на треках 1 и 3, CHORD — на треке 2.
3. Трек 4 → бит, трек 1 → бас, трек 2 → аккорды, трек 3 → мелодия.
4. Готовый луп — **SAVE + клавиша 5** (секция A). Меняй и сохраняй B, C, D.
5. **SAVE + клавиша 14** (SONG REC) и играй секции SAVE + 1–4 — песня запишется сама.

> **8 голосов на три синт-трека.** Аккорд 7TH = 4 голоса, пэд 4 ноты = 4 голоса. Басы и лиды ставь в **VCE = MONO** — тогда голосов хватит. Если ноты начали пропадать — SLOOP аккуратно гасит лишние, но лучше упростить аккорд до TRIAD.

### 1 · Бум-бэп

| | |
| --- | --- |
| **Темп / лад** | 90 BPM · KEY D · MIN · глобальный SWING 0, у треков — по своему |
| **Трек 4** | D02 · кит BOOMBAP · SWG 40 |
| **Трек 1** | B01 · UP BASS · OCT −2 · SWG 32 |
| **Трек 2** | DUSTY PNO · CHORD 7TH · P21 (i7 – iv7) · ритм R11 · SWG 32 |
| **Трек 3** | HORN STAB · LEN 32 · только шаги 1 и 27 (два «удара» за 2 такта) |
| **Эффекты** | DUST 25 % · REV трека 2 — 30 % |
| **Секции** | A: всё без трека 3 · B: + HORN STAB, D02 с OHAT · C: только пиано и хэты · D: F09 «стоп» |
| **Песня** | A A B A B C B D |
